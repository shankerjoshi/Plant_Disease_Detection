# Plant_Disease_Detection
Plant disease detection using CNN ( Convolutional Neural Network ) trained on PlantVillage dataset ( link : https://www.kaggle.com/datasets/moazeldsokyx/plantvillage ).
Used the pretrained model MobileNetV2 as the base model for higher accuracy.
